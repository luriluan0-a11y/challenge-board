# 앱스 스크립트 설정 안내 (선생님용)

챌린지보드의 서버(로그인 확인, 기록 저장)를 선생님 구글 계정에 만드는 순서다. 한 번만 하면 된다. 약 20분.

> 화면의 메뉴 이름은 구글이 바꿀 수 있다. 비슷한 이름을 찾으면 된다.

---

## 1단계. 시트 만들고 코드 붙여 넣기

1. [구글 드라이브](https://drive.google.com) → **새로 만들기 → Google 스프레드시트**. 이름은 `챌린지보드`.
2. 시트 메뉴 **확장 프로그램 → Apps Script**. 왼쪽 위 프로젝트 이름을 `챌린지보드 서버`로 바꾼다.
3. 기본으로 있는 `Code.gs`의 내용을 모두 지우고, 저장소의 [`gas/Code.js`](../gas/Code.js) 내용을 붙여 넣는다.
4. 왼쪽 **파일 옆 + → 스크립트** → 이름 `Auth` → [`gas/Auth.js`](../gas/Auth.js) 내용을 붙여 넣는다.
5. **저장**(디스크 아이콘).
6. 위쪽 함수 선택 칸에서 **`setupSheets`**를 고르고 **실행**.
   - "권한 검토" 창이 뜨면 내 계정 선택 → **고급 → 챌린지보드 서버(으)로 이동(안전하지 않음)** → 허용.
   - 내가 만든 스크립트라서 나오는 경고다. 허용하는 권한: 이 시트 읽고 쓰기, 구글 로그인 확인용 인터넷 요청.
7. 시트로 돌아가면 탭 8개가 생겨 있다: 학생명단, 매일챌린지, 미션, 설정, 세션(숨김), 체크기록, 미션인증, 보석뽑기.

## 2단계. 로그인용 "클라이언트 ID" 만들기

학생이 "구글로 로그인" 버튼을 누를 수 있게 하는 번호다. **비밀 정보가 아니며**, 정해 둔 주소(Vercel 사이트)에서만 쓸 수 있게 묶어 둔다.

1. [구글 클라우드 콘솔](https://console.cloud.google.com) → 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `challenge-board` → 만들기.
2. 메뉴 **API 및 서비스 → OAuth 동의 화면** (또는 **Google 인증 플랫폼**) → **시작하기**
   - 앱 이름: `챌린지보드`, 사용자 지원 이메일: 내 이메일
   - 대상: **외부**
   - 연락처 이메일: 내 이메일 → 동의하고 만들기
3. **대상(Audience)** 메뉴 → 게시 상태를 **앱 게시(프로덕션)** 로 바꾼다.
   - "테스트" 상태로 두면 직접 추가한 테스트 사용자만 로그인할 수 있다.
   - 이메일·이름만 쓰는 기본 로그인이라 구글 심사는 필요 없다.
4. **클라이언트 → 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**, 이름: `challenge-board-web`
   - **승인된 JavaScript 원본**에 두 줄 추가:
     - `https://challenge-board-seven.vercel.app` (학생들이 쓰는 주소)
     - `http://localhost:8765` (내 컴퓨터에서 시험할 때)
   - 만들기 → 나오는 **클라이언트 ID**(`…apps.googleusercontent.com`)를 복사한다. (클라이언트 보안 비밀번호는 쓰지 않는다. 어디에도 붙여 넣지 않는다.)
5. 시트 **설정** 탭 → `로그인 클라이언트 ID` 줄의 **값** 칸에 붙여 넣는다.

## 3단계. 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
   - 설명: `챌린지보드 서버 v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
4. 새 탭에서 그 주소를 열어 `{"ok":true,"service":"challenge-board"}`가 보이면 성공.
5. 이 **웹 앱 URL**과 **클라이언트 ID**를 Claude에게 알려 준다 → 로그인 화면에 연결한다.

> "모든 사용자"로 열어도 안전한 이유: 모든 요청은 구글 로그인 토큰 확인 → 학생명단 대조를 통과해야 한다. 학생 정보는 이 시트에만 있고 GitHub에는 올라가지 않는다.

## 4단계. 학생 명단 채우기

- **학생명단** 탭의 예시 줄을 지우고, 한 줄에 한 명씩 **이메일 / 이름**을 적는다.
- `이름확인` 칸은 비워 둔다. 학생이 처음 로그인해서 이름을 맞히면 스크립트가 날짜를 적는다.
- 학생을 빼려면 그 줄을 지운다. 이미 로그인한 학생도 다음 요청부터 막힌다.

## 코드를 고쳤을 때

Apps Script에 새 코드를 붙여 넣은 뒤 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 이렇게 하면 웹 앱 URL이 바뀌지 않는다. ("새 배포"를 누르면 URL이 바뀐다.)

## 문제가 생기면

| 화면 메시지 | 확인할 것 |
| --- | --- |
| 선생님이 아직 로그인 설정을 마치지 않았어요 | 설정 탭에 클라이언트 ID를 넣었나 |
| 구글 로그인을 확인하지 못했어요 | 클라이언트 ID가 정확한가, 승인된 JavaScript 원본에 주소가 있나 |
| 등록되지 않은 계정이에요 | 학생명단에 그 이메일이 있나 (화면에 학생 이메일이 표시됨) |
| 이름이 명단과 달라요 | 학생명단의 이름 철자 (띄어쓰기는 상관없음) |
| "○○ 탭이 없어요" | 시트 메뉴 **챌린지보드 → 처음 설정**을 실행 |
