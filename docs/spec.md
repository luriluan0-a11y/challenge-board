# 챌린지보드 설계 (학생용, 2026-11-13 /grill-me로 정함)

한 반 학생들이 함께 쓰는 챌린지보드. 학생은 매일 챌린지를 체크하고 미션을 인증해 포인트를 모으고, 포인트로 보석을 뽑아 순위를 겨룬다. 학기 단위로 운영하고 학기가 끝나면 초기화한다.

> 처음에는 나만 쓰는 개인 보드로 설계했다가(아래 "바뀐 기록"), 같은 날 학생용으로 바꿨다.

## 정한 것

| 항목 | 내용 |
| --- | --- |
| 사용자 | 한 반. 선생님이 학생 이름과 이메일을 받아 구글 시트 "학생명단"에 정리한다 |
| 로그인 | 구글 로그인 → 앱스 스크립트가 구글 로그인 토큰을 확인 → 명단에 있는 이메일인지 확인 → 처음 한 번 학생이 이름을 입력해 명단 이름과 대조(띄어쓰기 무시). 한 번 맞히면 다음부터는 묻지 않는다 |
| 자료 보관 | 선생님 구글 드라이브의 시트(명단·설정·기록)와 인증 폴더. GitHub(공개)에는 학생 정보를 두지 않는다 |
| 서버 | 구글 앱스 스크립트 웹 앱. 로그인 확인, 기록 저장, 보석 뽑기(확률)를 모두 서버에서 처리한다 (화면에서 하면 조작할 수 있으므로) |
| 매일 챌린지 | 선생님이 시트 "매일챌린지"에 정한 공통 항목. 학생이 체크만 하면 그날 1회 (선생님 확인 없음) |
| 미션 | 선생님이 시트 "미션"에 등록. 학기 중 한 번, 인증(사진·링크·글)을 올리면 바로 완료 (반려 없음). 학생은 미션을 만들지 않는다 |
| 인증 갤러리 | 같은 반 모두가 본다. 올릴 때 "얼굴·이름·연락처·학번 같은 개인정보는 가리고 올려 주세요" 안내 |
| 포인트 (기본값) | 매일 챌린지 체크 +10, 그날 모두 체크 보너스 +30, 미션 인증 +20. 시트 "설정"에서 바꾼다 |
| 보석 챌린지 | 포인트를 써서 보석을 뽑는다. 💎 투명 1점(40%) · ⚪ 흰색 2점(28%) · 🩷 핑크 3점(18%) · 🟡 골드 4점(10%) · ⚫ 검은색 5점(4%). 확률과 뽑기 비용은 시트 "설정"에서 바꾸고 테스트하며 정한다 |
| 컴플리트 | 5종류를 모두 모으면 컴플리트 |
| 순위 | 컴플리트 먼저, 그다음 보석 점수 합계. 실시간 반영. 순위 1등에게 선생님이 상을 준다 |
| 학기 | 시트 "설정"의 학기 이름을 바꾸면 새 학기로 시작. 지난 학기 기록은 시트에 남는다 |
| 하루 바뀌는 시각 | 새벽 4시 |
| 화면 탭 | 오늘(매일 챌린지) · 미션(인증) · 보석(뽑기·내 보석함) · 순위 · 갤러리 |
| 개발 | TDD. 계산은 순수 함수로 두고 테스트를 먼저 쓴다. 앱스 스크립트의 계산 파일(`gas/Auth.js` 등)도 Node 테스트로 검사한다 |
| 배포 | 화면은 Vercel https://challenge-board-seven.vercel.app/ (테스트 통과 시에만 배포, GitHub Pages는 끔). 서버는 앱스 스크립트 웹 앱 |
| 올리기 | 기능 하나가 끝나면 사용자에게 보여 주고 허락받은 뒤 묶어서 push. 커밋 이메일은 GitHub 비공개용 |

## 만드는 순서

1. 로그인과 명단 확인 (시트 + 앱스 스크립트)
2. 오늘 탭: 매일 챌린지 체크와 포인트
3. 미션 탭과 인증 갤러리
4. 보석 탭: 뽑기와 내 보석함
5. 순위 탭

## 시트 구성 (앱스 스크립트 "처음 설정"이 자동으로 만든다)

| 탭 | 칸 |
| --- | --- |
| 학생명단 | 이메일, 이름, 이름확인(날짜, 스크립트가 채움), 메모 |
| 매일챌린지 | ID, 이름, 이모지, 사용(Y/N) |
| 미션 | ID, 이름, 설명, 인증방법(사진/링크/글), 사용(Y/N) |
| 설정 | 항목, 값 (학기, 로그인 클라이언트 ID, 포인트, 뽑기 비용, 보석 확률) |
| 세션 | 로그인 상태 (토큰은 원문 대신 해시만 저장) |
| 체크기록 · 미션인증 · 보석뽑기 | 2~4번 기능에서 쓴다 |

## 바뀐 기록

- 2026-11-13 오후: 학생용으로 변경. 구글 로그인 + 명단 확인, 구글 시트·앱스 스크립트 저장, 매일 챌린지·미션·보석 챌린지·순위로 바꿨다. 보상 상점, 한 줄 메모, 도장·배지는 뺐다.
