# 챌린지보드 설계 (2026-11-13, /grill-me로 정함)

취업 준비를 돕는 개인 챌린지보드. 매일 습관·공부를 체크해 달성률과 포인트를 쌓고, 추가 미션을 날짜별로 기록한다.

## 정한 것

| # | 결정 |
| --- | --- |
| 기록 위치 | 보드 하나로 기록한다. 마크다운 습관트래커는 더 만들지 않는다 (10월 파일은 그대로 둠). 기록은 2026-11-13부터 |
| 매일 항목 (9개) | 💊 아침 영양제, 🚶 산책 30분, 🗣️ 스픽, 🦉 듀오링고, 📊 컴퓨터활용능력, ✉️ 더캠프, 💊 저녁 영양제, 📮 지원 건수, 💻 코드·AI 공부 |
| 기록 방식 | 모두 체크. "지원 건수"만 체크하면 건수 칸이 열린다 (기본 1) |
| 한 줄 메모 | 매일 항목과 따로, 하루 하나. 지난 메모 모아 보기 |
| 보여 줄 것 | 오늘 달성률 + 보상 (포인트·보상 상점 + 도장·배지) |
| 포인트 | 항목 체크 +10, 하루 100% 보너스 +30, 미션 기록 +20 (미션마다 하루 한 번), 메모 +5, 배지 +50. 체크를 풀면 포인트도 빠진다. 숫자는 설정에서 바꿀 수 있다 |
| 도장 | 하루 100%면 달력에 🐾 |
| 배지 | 🔥 100% 연속 3·7·14·30일 / 📮 첫 지원·지원 10건·30건 (실제 건수) / 💻 코드·AI 공부 누적 7·30일 / 🎯 미션 기록 10번. 한 번 받으면 사라지지 않는다 |
| 보상 상점 | ☕ 라떼 한 잔 100, 🎮 게임 1시간 150, 🍰 디저트 200. 보상은 화면에서 추가·수정. 구매하면 포인트가 빠지고 내역이 남는다 |
| 추가 미션 | 이름 + 날짜별 기록(한 줄 내용 + 링크 선택) + 보관하기. 처음 미션: "명령어 입력 연습 7개", "프로그래밍 공부" |
| 매일 항목 바꾸기 | 추가·이름 바꾸기·숨기기·순서 바꾸기. 완전 삭제는 없다. 숨긴 날부터 달성률에서 빠진다 |
| 하루 바뀌는 시각 | 새벽 4시 (설정에서 0~6시) |
| 화면 | 탭 5개: 오늘 · 미션 · 보상 · 기록 · 설정. 휴대폰에서는 아래, 넓은 화면에서는 위 |
| 저장 | 브라우저 저장소(localStorage) + 백업 내보내기·불러오기. 나중에 구글 로그인 + Firebase로 옮긴다 |
| 공개 | 지금은 로그인 없이 공개 페이지 (기록은 각자 브라우저에만 있음) |
| 기술 | HTML·CSS·JavaScript (빌드 없음). 계산은 `src/core.js` 순수 함수, Node 기본 테스트(`node --test`)로 TDD |
| 배포 | GitHub Actions가 테스트를 통과할 때만 GitHub Pages에 배포 |
| 올리기 | 기능 하나가 끝나면 사용자에게 보여 주고 허락받은 뒤 묶어서 push |

## 만드는 순서

1. 뼈대 + 오늘 탭 (체크, 지원 건수, 메모, 달성률, 포인트, 저장, 자동 테스트·배포)
2. 기록 탭 (달력 도장, 연속 일수, 배지, 지난 메모)
3. 보상 탭 (잔액, 상점, 구매 내역, 보상 추가)
4. 미션 탭 (미션, 날짜별 기록 + 링크, 보관함)
5. 설정 탭 (항목·포인트·하루 시각, 백업)

## 나중에

- 구글 로그인 + Firebase로 기기 간 동기화
