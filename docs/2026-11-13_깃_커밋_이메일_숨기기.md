# 깃 커밋 이메일 숨기기 (GitHub noreply 이메일)

- 만든 날: 2026-11-13
- 계기: 챌린지보드를 공개 저장소에 올리기 전, 커밋 작성자 이메일이 개인 이메일로 되어 있는 것을 발견
- 관련 노트: [[2026-10-23_IDE]] · [[2026-10-30_CLI]] · [[2026-10-16_웹페이지_제작과_GitHub_Pages_배포]]

> **한 줄 정리**: 커밋에는 작성자 이름과 **이메일**이 함께 저장되고, 공개 저장소에서는 누구나 볼 수 있다. GitHub가 주는 **비공개용 이메일(noreply)** 로 바꾸면 개인 이메일이 드러나지 않는다.

---

## 왜 드러날까

- 비유: 커밋은 **봉투에 넣은 편지**다. 봉투에는 보내는 사람 이름과 주소(이메일)가 적힌다. 공개 저장소는 이 봉투를 모두가 볼 수 있는 게시판에 붙여 두는 것과 같다.
- GitHub 화면에는 이메일이 잘 안 보이지만, 커밋 주소 끝에 `.patch`를 붙이면 바로 보인다. 스팸 업체가 이렇게 이메일을 모으기도 한다.

## 비공개용 이메일(noreply)이란

| | 개인 이메일 | GitHub 비공개용 이메일 |
| --- | --- | --- |
| 모양 | `내아이디@gmail.com` | `숫자ID+깃허브아이디@users.noreply.github.com` |
| 공개되면 | 스팸·피싱 메일이 올 수 있다 | 메일이 오지 않는 주소라 상관없다 |
| GitHub 잔디(기여 기록) | 계정에 연결됨 | 똑같이 내 계정으로 연결됨 |

내 비공개용 이메일: `225147029+luriluan0-a11y@users.noreply.github.com` (숫자는 `gh api user`로 확인한 내 GitHub 계정 번호)

## 고치는 방법

### 1. 앞으로 만드는 커밋 (저장소마다)

```bash
git config user.email "225147029+luriluan0-a11y@users.noreply.github.com"
```

- 그 저장소 폴더 안에서 실행한다. 모든 저장소에 한 번에 하려면 `--global`을 붙인다.
- 확인: `git config user.email`

### 2. 아직 올리지 않은 커밋 (작성자만 바꾸기)

```bash
git rebase --root --exec "git commit --amend --no-edit --reset-author"
```

- 1번을 먼저 한 뒤 실행한다. 모든 커밋의 작성자를 지금 설정으로 바꾼다. 내용은 그대로다.
- **올리기 전에만** 안전하다. 이미 올린 커밋에 하면 기록이 갈라진다.

### 3. GitHub 설정 (실수 막기)

GitHub → Settings → Emails

- ☑ **Keep my email addresses private**: 웹에서 만드는 커밋에 비공개용 이메일을 쓴다.
- ☑ **Block command line pushes that expose my email**: 개인 이메일이 든 커밋을 올리려고 하면 GitHub가 막아 준다.

### 4. 이미 올린 커밋

- 지난 커밋의 이메일까지 지우려면 기록을 다시 쓰고 강제로 올려야 한다(`git filter-repo` 등). 다른 사람이 받아 간 복사본에는 남고, 실수하면 저장소가 망가질 수 있어서 보통은 **앞으로만 바꾼다.**
